Party Stash v1.0

One infinite stash shared by the whole party, Pillars of Eternity style, built into a redesigned inventory page. For Baldur's Gate: Enhanced Edition (with or without Siege of Dragonspear), Baldur's Gate II: Enhanced Edition and EET.

Features

  • Shared stash: every party member reaches the same infinite stash on the inventory page. Quests still see the items stored in it.
  • New inventory page: backpack and stash in one scrollable grid, a ground column, compact 2×2 stats (attributes in 3 letters).
  • Tabs: All, Weapons, Armor, Gear, Ammo, Gems, Scrolls, Potions, Quest, Misc, Bags.
  • Sorting: Auto (each tab its own order: weapons and armor by quality, then AC and value; scrolls by class and level…), Date, Quality, Type, Price, Value/weight.
  • Hints: red = unusable by the shown character, blue = unidentified, + = an upgrade for him (or a scroll a party mage can still learn).
  • Sell Marked: Ctrl + click stash items, then sell them all at once at any merchant, with the total on the button.
  • Bags: a bag put in the stash is emptied into it and kept in the Bags tab; the stash items it can hold weigh nothing (a Bag of Holding: the whole stash).
  • Weight: the stash counts against the sum of the members' weight allowances; above it, the party is slowed down.
  • Two looks: Baldur's Gate 1 or Baldur's Gate II style, on either game.
  • Sorted loot (optional): ground piles, containers and the loot bar list quest items, then weightless items, then the rest by value/weight.

Requirements

Game version v2.7.x and EEex (installed first). A mod that replaces the inventory screen (LeUI, Dragonspear UI++…) conflicts with the new page.

Installation

  1. Install EEex.
  2. Extract the archive into the game folder (where chitin.key is).
  3. Run setup-PartyStash.exe, pick your language, choose a look (the one matching your game is recommended) and, if you like, Sorted loot.
  4. Start the game with InfinityLoader.exe (EEex).

Uninstalling

Empty the stash first, in game: Ctrl + left click on the big bag next to the weight. Your collected bags come back filled with the items they can hold; everything else drops on the ground. Then run setup-PartyStash.exe and uninstall. Otherwise the stash contents stay in your saves but cannot be reached until the mod is reinstalled.

Notes

  • From Baldur's Gate to Siege of Dragonspear, the stash is carried over as long as the game is not closed between the end of BG1 and the start of SoD.
