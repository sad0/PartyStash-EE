Party Stash v1.1

파티 전체가 공유하는 무한 보관함을 Pillars of Eternity 방식으로, 새로 디자인한 인벤토리 화면에 넣었습니다. Baldur's Gate: Enhanced Edition(Siege of Dragonspear 포함 여부 무관), Baldur's Gate II: Enhanced Edition, EET용.

기능

  • 공유 보관함: 모든 파티원이 인벤토리 화면에서 같은 무한 보관함을 사용합니다. 퀘스트는 보관함 안의 아이템도 인식합니다.
  • 새 인벤토리 화면: 배낭과 보관함을 하나의 스크롤 격자로, 바닥 열, 간결한 2×2 능력치(능력치 이름은 3글자).
  • 탭: 전체, 무기, 갑옷, 장비, 탄약, 보석, 두루마리, 물약, 퀘스트, 기타, 가방.
  • 정렬: 자동(탭마다 고유 순서: 무기와 갑옷은 품질, 그다음 AC와 가치; 두루마리는 직업과 레벨…), 날짜, 품질, 종류, 가격, 가치/무게.
  • 표시: 빨강 = 선택한 캐릭터가 사용 불가, 파랑 = 미감정, + = 그 캐릭터에게 업그레이드(또는 파티 마법사가 아직 배울 수 있는 두루마리).
  • 표시 판매: 보관함 아이템을 Ctrl + 클릭한 뒤 아무 상인에게서나 한꺼번에 판매하며, 버튼에 합계가 표시됩니다.
  • 가방: 보관함에 넣은 가방은 내용물이 보관함으로 옮겨지고 가방 탭에 남습니다. 그 가방이 담을 수 있는 보관함 아이템은 무게가 없습니다(소지의 가방: 보관함 전체).
  • 무게: 보관함은 구성원 최대 적재량의 합에 포함되며, 이를 넘으면 파티가 느려집니다.
  • 두 가지 외형: 두 게임 모두에서 발더스 게이트 1 또는 발더스 게이트 II 스타일.
  • 정렬된 전리품(선택): 바닥 더미, 컨테이너, 전리품 바에서 퀘스트 아이템, 무게 없는 아이템, 나머지는 가치/무게 순으로 표시.

요구 사항

게임 버전 v2.7.x와 EEex(먼저 설치). 인벤토리 화면을 교체하는 모드(Dragonspear UI++ 등)는 새 화면과 충돌합니다. LeUI는 Party Stash와 함께 작동합니다: Baldur's Gate II 외형을 선택하세요.

설치

  1. EEex를 설치합니다.
  2. 압축 파일을 게임 폴더(chitin.key가 있는 곳)에 풉니다.
  3. setup-PartyStash.exe를 실행하고 언어, 외형(게임에 맞는 것을 권장), 원하면 정렬된 전리품을 고릅니다.
  4. InfinityLoader.exe(EEex)로 게임을 실행합니다.

조작(인벤토리 화면)

동작조작
보관함에서 아이템 꺼내기클릭(더블클릭: 꺼내서 장착)
배낭 아이템 보관Shift + 더블클릭, 또는 보관함 격자에 놓기
배낭 전체 보관"모두 보관" 버튼 또는 스페이스
판매 표시/해제보관함 아이템을 Ctrl + 클릭한 뒤 상인에게서 "표시 판매"
설명오른쪽 클릭
격자, 탭, 바닥 스크롤마우스 휠, 화살표
가방 보관Shift + 더블클릭 또는 "모두 보관"(확인 후)
보관함 비우기(제거 전)무게 옆의 큰 가방을 Ctrl + 왼쪽 클릭

제거

먼저 게임에서 보관함을 비우세요: 무게 옆의 큰 가방을 Ctrl + 왼쪽 클릭. 모은 가방은 담을 수 있는 아이템으로 채워져 돌아오고, 나머지는 모두 바닥에 떨어집니다. 그다음 setup-PartyStash.exe를 실행해 제거하세요. 그렇지 않으면 보관함 내용은 저장 파일에 남지만 다시 설치할 때까지 꺼낼 수 없습니다.

참고

  • 발더스 게이트에서 Siege of Dragonspear로 넘어갈 때, BG1 끝과 SoD 시작 사이에 게임을 닫지 않으면 보관함이 이어집니다.
  • 번역 개선을 환영합니다: PartyStash/tra/.
  • EET (Enhanced Edition Trilogy): 작동할 것입니다 (BG2:EE처럼 설치됨) 하지만 아직 테스트하지 않았습니다. 의견 환영합니다.
