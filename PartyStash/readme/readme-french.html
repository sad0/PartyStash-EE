Party Stash v1.2

Un coffre infini partagé par tout le groupe, façon Pillars of Eternity, intégré à une page d'inventaire repensée. Pour Baldur's Gate: Enhanced Edition (avec ou sans Siege of Dragonspear), Baldur's Gate II: Enhanced Edition et EET.

Fonctionnalités

  • Coffre partagé : tous les membres du groupe accèdent au même coffre infini sur la page d'inventaire. Les quêtes voient toujours les objets rangés dedans.
  • Nouvelle page d'inventaire : sac à dos et coffre dans une seule grille défilante, une colonne pour le sol, des stats compactes en 2×2 (caractéristiques en 3 lettres).
  • Onglets : Tout, Armes, Armure, Équipement, Munitions, Gemmes, Parchemins, Potions, Quête, Divers, Sacs.
  • Tri : Auto (chaque onglet a son ordre : armes par dégâts par round pour le perso affiché, armures par CA, parchemins par classe et niveau…), Date, Qualité, Type, Prix, Valeur/poids. Clic droit sur le bouton de tri pour l'inverser.
  • Repères : rouge = inutilisable par le perso affiché, bleu = non identifié, + = une amélioration pour lui (ou un parchemin qu'un mage du groupe peut encore apprendre).
  • Marques : Ctrl + clic sur un objet (coffre, sac à dos ou équipé) pour le cocher pour la vente (assombri), encore pour le rendre précieux (doré), encore pour l'effacer. Vendre cochés vend d'un coup tous les objets cochés chez n'importe quel marchand, avec le total sur le bouton.
  • Dégâts par round : les infobulles des armes affichent les dégâts par round et le TAC0 pour le perso affiché (force, compétences, attaques par round, les deux mains en combat à deux armes) ; les stats affichent les attaques par round.
  • Charges : les baguettes et autres objets à charges affichent leurs charges dans le coin de leur case.
  • Objets précieux : jamais vendus, ignorés par Tout ranger et par la sélection des marchands, et impossibles à poser au sol. Un objet du sac à dos coché pour la vente part directement au coffre.
  • Dépôt : clic droit sur le gros sac à côté du poids, puis ouvrez un conteneur, et choisissez d'y déposer le sac à dos ou la page du coffre affichée (les objets précieux et de quête restent).
  • Options (composants séparés) : le coffre ne pèse rien ; garder l'or du groupe aux changements de campagne (BG1 vers SoD, SoD vers BG2 dans EET) ; hardcore : ces changements vident aussi le coffre.
  • Sacs : un sac rangé dans le coffre y est vidé et gardé dans l'onglet Sacs ; les objets du coffre qu'il peut contenir ne pèsent rien (un Sac de contenance : tout le coffre).
  • Poids : le coffre compte dans la somme des charges maximales des membres ; au-delà, le groupe est ralenti.
  • Deux looks : style Baldur's Gate 1 ou Baldur's Gate II, sur les deux jeux.
  • Butin trié (optionnel) : au sol, dans les contenants et dans la barre de butin, les objets de quête, puis les objets sans poids, puis le reste par valeur/poids.

Prérequis

Jeu en version v2.6.6 ou v2.7.x, et EEex (installé avant). Un mod qui remplace l'écran d'inventaire (Dragonspear UI++…) entre en conflit avec la nouvelle page. LeUI fonctionne avec Party Stash : choisissez le look Baldur's Gate II. Infinity UI++ s'installe et tourne dans nos tests ; les retours sont les bienvenus.

Installation

  1. Installez EEex.
  2. Décompressez l'archive dans le dossier du jeu (là où se trouve chitin.key).
  3. Lancez setup-PartyStash.exe, choisissez la langue, un look (celui de votre jeu est recommandé) et, si vous voulez, Butin trié.
  4. Lancez le jeu avec InfinityLoader.exe (EEex).

Désinstallation

Videz d'abord le coffre en jeu : Ctrl + clic gauche sur le gros sac à côté du poids. Vos sacs collectionnés reviennent remplis des objets qu'ils peuvent contenir ; tout le reste tombe au sol. Puis lancez setup-PartyStash.exe et désinstallez. Sinon, le contenu du coffre reste dans vos sauvegardes mais devient inaccessible jusqu'à la réinstallation du mod.

FAQ

Comment marche le tri ? Chaque onglet a son tri par défaut (Auto : armes par dégâts par round, armures par CA, parchemins par classe et niveau…), ou bien vous choisissez Date, Qualité, Type, Prix ou po/lb.

Et les sacs, même les sacs sans fond ? Pas d'imbrication. Un sac mis dans le coffre y est vidé puis rangé dans l'onglet Sacs : le coffre reste une seule liste. Chaque sac collectionné rend sans poids les objets du coffre qu'il pourrait contenir. Un sac sans fond couvre tous les types : avec lui, le coffre entier ne pèse rien.

Je ramasse absolument tout. C'est un problème ? Le coffre est infini. Sans sac sans fond, son poids compte dans la capacité cumulée du groupe (au-delà, tout le monde est ralenti). Tout ranger vide un sac à dos en un clic, et Vendre cochés vend d'un coup tout ce que vous avez marqué, chez n'importe quel marchand.

Est-ce que ça ralentit le jeu ? Aucun hook par créature (ni opcode, ni script, ni action) : le travail est espacé (une vérification toutes les 500 ms, le poids du groupe toutes les 2 s), donc le nombre de créatures à l'écran ne change pas son coût.

Remarques

  • De Baldur's Gate à Siege of Dragonspear, le coffre suit tant que le jeu n'est pas fermé entre la fin de BG1 et le début de SoD.
  • Les traductions sont les bienvenues : PartyStash/tra/.
  • EET (Enhanced Edition Trilogy) : testé en v2.6.6. Le coffre survit au passage de Siege of Dragonspear à Baldur's Gate II.
